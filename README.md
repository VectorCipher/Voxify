# Voxify

An AI-powered voice assistant designed for EdTech platforms, allowing parents to speak naturally and receive accurate, voice-based responses about their child’s academic performance.

## 🚀 Features

🎙️ Voice-based parent interaction

📊 Student report-card–aware responses (no hallucinations)

🧠 Contextual, polite, teacher-like explanations

🔊 AI-generated voice responses (saved & replayable)

🧾 Supports queries by student name or roll number

🧠 Multi-turn conversation flow (asks student info first)

📂 Clean backend architecture (easy to extend)
